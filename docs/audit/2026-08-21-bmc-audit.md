## 4. 厂商差异结论

| 维度 | Dell | 浪潮 |
|---|---|---|
| 双路径存在性 | 仅 legacy `Power`/`Thermal`（无 PowerSubsystem/ThermalSubsystem/EnvironmentMetrics/Controls） | 同左（两家都只有旧式路径） |
| Sensors 集合 | **有**（21 成员，全带 Thresholds/Reading） | **无**（需回退 legacy Thermal/Power） |
| Storage | 完整（3 控制器/6 盘/3 卷，Oem.Dell.DellPhysicalDisk） | 不可用（成员详情 17034 错误） |
| Network | System 级 EthernetInterfaces（2，含 LinkStatus/SpeedMbps） | 无 EthernetInterfaces；仅 chassis NetworkAdapters/PCIeDevices |
| 会话行为 | 标准（Sessions/1→404；create-session 响应符合 schema） | 非标准（Sessions/1→200 `{}`；create 响应缺 `Name`；探测期间服务器经 cookie 认证自动签发 1 会话） |
| 分页 | 顶层集合不分页；日志条目 `Members@odata.nextLink`（Lclog 1062 条，50/页） | 同左（SEL/AuditLog/IDL 100 条，`?$skip=100&$top=100`） |
| 延迟 | mean 234.8 ms（max 306 ms） | mean 1480 ms（max 1981 ms），约 6.3× |
| 固件面 | 22 项 + HttpPushUri/Multipart | 3 项、无 push URI |
| PowerMetrics | 有（min/max/avg） | 无（仅瞬时功耗） |
| OEM 键 | `Oem.Dell`（DellSystem/DellChassis/DellEnclosure，含 rollup 状态） | `Oem.Public`（ProductName/CPU/Memory 使用率、DeviceMaxNum、Mainboard） |
| 口令类字段 | 均无（两家 BIOS 属性均无口令类字段；快照中相关属性值全为 null/空） | 同左 |

共性结论：① 两家都只暴露 legacy Power/Thermal，采集设计应直指 `/redfish/v1/Chassis/{id}/Power` 与 `/Thermal`；② 两家日志条目都分页（`Members@odata.nextLink`），分页是必需能力而非可选；③ 浪潮在所有维度都更"薄"（无 Sensors/存储/网卡明细/min-max-avg 功耗），厂商分支不可省；④ BIOS 属性镜像采集必须排除口令类字段名（Dell: SysPassword/SetupPassword/哈希与 iSCSI CHAP；浪潮: AdministratorPassword/UserPassword——快照中值均为 null/空，仍不得导出）。

## 5. 分频设计输入

K 组实测（6 请求，顺序探测）：

| | Dell | 浪潮 |
|---|---|---|
| per-request ms | 244/194/232/306/220/213 | 392/1455/1529/1844/1981/1679 |
| mean ms | 234.8 | 1480.0 |
| max ms | 306 | 1981 |
| 单轮请求数（A–I 组实测口径） | ≈98 | ≈45 |
| 估算轮耗时（顺序） | 98×235ms ≈ **23s**（≤30s） | 45×1480ms ≈ **67s**（最坏 45×1981ms ≈ **89s**） |

交叉验证：实跑中 Dell 全轮仅 **7.69s**（ETag/304 缓存 + 轮内并行起效，低于探测上限估算）；浪潮实跑捕获窗口内 4 轮均超时（≥60s），与估算一致。

建议：

1. **slow_interval ≥ 120s**：浪潮顺序最坏 ~89s + 裕量，120s 为 spec 慢组设计的安全默认下限；Dell 慢组同样受益（固件 22 项、Lclog 1062 条在快组只会拖累）。
2. **快组内容必须受截止期约束**：Dell 全量 ≈23s 可容入 30s；浪潮即使"快组"≈45 请求 × 1.5s 也超 60s——浪潮侧要么 per-BMC 并发（请求数不变但 wall-clock 可压到单请求延迟量级），要么缩减请求面（跳过不可用子资源，如 H 组 17034 存储错误体），否则快组对浪潮形同虚设。
3. 慢组候选清单（spec 第 3 节）：storage、network、firmware、assembly、event_log、bios——前四项两家均有实体数据，后两项为缺口补建（见 AUDIT-5）。
