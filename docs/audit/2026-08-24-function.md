## 结论
**PASS**

8 个新指标族全部实现并在两台真机实跑验证通过（数值与探测数据逐项一致）；安全/稳定/资源回归全绿；性能回归硬阈值全绿；mock 管道 round/encode/bytes 相对基线 +16~25% 的增长经同日同机 A/B 对照确认源于新族固有负载（载荷/序列 +23%），已按评审裁决 R1 将 round/encode/bytes 重设基线（round 0.37–0.38 / encode 0.081–0.085 / bytes 10949）；绝对余量巨大（round 0.37ms vs 2000ms 阈值、encode 0.08ms vs 500ms 阈值），真机热路径与轮耗时无变化。

D1 指标覆盖补齐（P1 可靠性 backlog 维持）/ D2 全清单探测门控（MET 实现、NOT MET 记 backlog）/ D3 仓库惯例（redfish_ 前缀 + 单位后缀、label 复用、驱动/控制器归慢组、CPU/LED 归快组）/ D4 mock e2e + 真机实跑验证（本记录 S2/S3 证据）

## 评审裁决记录（review rulings）
- **R1**：mock 管道 round/encode/bytes 增长为新族预期固有成本（同日同机 A/B 证实），round/encode/bytes 全部重设基线（round 0.37–0.38ms / encode 0.081–0.085ms / bytes 10949），§6.3 ±5% 容差不再适用于新族新增负载，仅适用于既有族回归。
- **R2**：resource per-BMC 系数 0.21 接受为单样本 RSS 噪声（既有「单样本 RSS 噪声」caveat 内，与编码字节 +23.1% 同比例，每字节系数稳定）。
- **R3**：浪潮 session 建立失败（`missing field \`Name\``）归入 AUDIT-4（P1 可靠性 backlog）——固件既有行为，basic auth 兜底可用，非本次引入、不阻塞本次验收。

- **perf_test**（release + PERF_ASSERT=1，硬阈值 hot<10ms/encode<500ms/round<2000ms 全绿）：

| 指标 | 基线（性能维验收） | 同日同机复测 @5f80350（功能维前） | 本维 HEAD 两次 | 判定（R1 后） |
|---|---|---|---|---|
| round_ms_med | 0.33 | 0.31 / 0.32 | **0.37 / 0.38** | ✅ R1 重设基线（+16~22%，新族固有负载） |
| encode_ms_med | 0.06 | 0.068 / 0.070 | **0.081 / 0.085** | ✅ R1 重设基线（+16~25%，新族固有负载） |
| hot_path_ms_med（min/max） | 0.0005（0.0003/0.0028） | 0.0006（0.0004/0.0028–0.0031） | 0.0006（0.0004/0.0034–0.0038） | ✅ 中位数不变（±5% 内） |
| bytes | 8896 | 8896 | **10949** | ✅ 新基线 10949（+23.1%，预声明增长） |
| rss_mb | ~10.9 | 11.0 / 11.6 | 11.1 / 11.9 | ✅ 无变化（噪声内） |

  - round/encode 增长归因：新族带来的确定性负载——mock 载荷增大（CPU2 处理器 + OEM 块、StorageControllers、盘 OEM、LED 字段）+ 序列数 +23%（8896→10949 bytes），解析/注册/编码工作量同步增长；非既有路径劣化（既有族语义冻结、等价性测试绿）。绝对余量巨大（round 0.37ms vs 2000ms、encode 0.08ms vs 500ms）；真机轮耗时 BMC 请求主导（Dell 快组 ~11s 级、浪潮快组 ~46s / 全量 152–154s，与性能维基线 44–48s / 150–156s 一致），+0.06ms/轮可忽略；/metrics 服务端热路径为预编码快照，真机输出与性能维同量级。**R1 裁决**：round/encode/bytes 增长为新族预期固有成本，全部重设基线（round 0.37–0.38 / encode 0.081–0.085 / bytes 10949），§6.3 ±5% 容差仅适用于既有族回归（hot_path 中位数不变、既有族语义冻结、等价性测试绿）。
- **resource_test**（release + RES_ASSERT=1 ✅）：`rss_1_2_3_4_mb=10.57/10.71/10.90/11.19`、`per_bmc_rss_delta_mb=0.21`、`encoded_bytes_per_bmc=10871`（基线 8829，+23.1% 与序列增长同比例）。per-BMC 系数 0.21 略高于既有观测区间 0.14–0.2——**R2 裁决**：接受为单样本 RSS 噪声（既有「单样本 RSS 噪声」caveat 内；与编码字节同比例增长、每字节系数稳定），不另行处置。
