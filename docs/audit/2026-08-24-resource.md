perf 实测（新打印精度：encode 3 位小数 / hot_path 6 位小数；基线 0.33 / 0.06 / 0.0005 / 8896 / 10.9）：

```
run1: round_ms_med=0.32 encode_ms_med=0.066 hot_path_ms_med=0.000600 bytes=8896 rss_mb=11.1
run2: round_ms_med=0.32 encode_ms_med=0.065 hot_path_ms_med=0.000500 bytes=8896 rss_mb=10.8
run3: round_ms_med=0.32 encode_ms_med=0.069 hot_path_ms_med=0.000600 bytes=8896 rss_mb=10.8
run4: round_ms_med=0.33 encode_ms_med=0.063 hot_path_ms_med=0.000500 bytes=8896 rss_mb=11.0
（PERF_ASSERT=1 同精度复测：1 passed；hot<10ms / encode<500ms / round<2000ms 软阈值余量 2–4 个数量级）
```

- round_ms_med 0.32–0.33 vs 基线 0.33：全部 ±3.1% 内 ✓
- bytes 8896 = 基线 8896（min 8894–8895 / max 8896 分布不变，4/4 次）✓
- rss_mb 10.8–11.1 vs 基线 10.9：全部 ±1.8% 内 ✓（单点采样设计噪声已见 10.8–11.6 区间，本次 4 次均容差内）
- hot_path_ms_med 0.000500 / 0.000600 交替（各 2/4 次）vs 基线 0.0005：采样值落在 Windows QPC 100ns tick 网格上，±5% 容差带（±25ns）低于仪器分辨率；名义偏差 0 或 +100ns（+20%），绝对量 0.1µs——测量分辨率地板噪声，无法严格判定（如实标注，不声称容差内）
- encode_ms_med 0.063–0.069 vs 基线 0.06：基线打印精度 2 位小数（真值 ∈ [0.055, 0.065)），粗于 ±5% 容差带（±3µs）；实测值跨基线打印区间顶沿，4 次自扩散 ±4.5%，与名义偏差（+5%–15%）同量级；编码路径本维零改动、输出字节 4/4 次恒等 8896，绝对量 65µs 距 500ms 阈值 4 个数量级——环境噪声，无回归信号（如实标注，不声称容差内）

## 遗留跟踪

- prometheus 存储替换/驻留压降（D1 排除，违反「优先社区资源」规则）
- N×walk 共享预取 / per-BMC 并发（性能维已排除）
- gzip/流式输出、流式响应上限（既有 backlog 维持）
- 浪潮 BMC 侧 keepalive 超时设置量化（本次仅得寿命窗口，设置值未量化——如需进一步佐证连接重建周期，可后续实测）
- perf 基线再校准（本次提高打印精度后 encode/hot_path 容差判定受旧基线打印精度限制；性能维基线应以新精度重测归档，作为后续回归对照）
- resource_test 稳定性：`encoded` 逐 BMC 严格相等断言在 4 次复测中出现 1 次失败（8828 vs 8829，mock 生成值长度方差 ±1 字节）；建议断言放宽为 ±1 字节或改为字节数曲线记录（Task 1 测试质量项，待 owner 处置）
